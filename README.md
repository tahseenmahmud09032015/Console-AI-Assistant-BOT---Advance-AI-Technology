## 🤖 What is Console AI Bot?

**Console AI Bot** is a lightweight, interactive Female/Girl (Named : Lily) AI assistant designed to run completely inside a terminal or server console. No web server, browser UI, or heavy frontend required! Whether hosted locally or deployed on server management panels, it provides a smooth, conversational AI experience right inside your command-line interface.

## ✅ Installation Proccess

 1.🖥️ Open any Python Server (Bot Hosting) on any Panel Similar to Pterodactyl Panel or Pterodactyl Panel itself. 

 2.📝 Make Sure the Server is Python 

 3.🗄️ Download all the Files from this Repository

 4.⬆️ Upload the Files into the Server

 5.⏮️ Open the app.py file

 6.🔃 In the Up There are a line "Update your API",Here Rename the Text with your AI API Key

 7.🔃 Then In the bottom line after the API Key line it will say " AI Model" Rename the Model of your AI you are using in this project

 8.⬇️ Go Down

 9.❓ Find the Section Permanent Facts,there u can Add some Facts about you or the Bots Personality and many important Things.Like there will be some example already given,you can add more.

 10.⏹️ After Editing,Save the file

 11.🟩 Start your Server,Now You are Ready to use it.
